# Todo List App

A simple, responsive browser-based todo list application built with plain HTML, CSS, and JavaScript.

## Features

- Add new tasks quickly.
- Mark tasks complete with a checkbox.
- Delete tasks.
- Filter tasks by All, Active, and Completed.
- Tasks persist in browser local storage.

## Project Structure

- `index.html` — main application UI.
- `styles.css` — styling and responsive layout.
- `script.js` — task management logic and local storage handling.

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in your preferred web browser.
3. Start adding tasks.

## Notes

- This app does not require a server.
- Data is stored locally in your browser and will remain between refreshes unless you clear browser storage.
